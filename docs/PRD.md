# PRD (Product Requirements Document)
# 반도체 시료 생산주문관리 시스템

**버전**: 1.0  
**작성일**: 2026-06-12  
**작성자**: KDH  

---

## 1. 배경 및 목적

### 1.1 배경

가상의 반도체 회사 "S-Semi"는 다양한 종류의 반도체 시료(Sample)를 생산하여 연구소, 팹리스(Fabless) 업체, 대학 연구실 등의 고객에게 납품하고 있다.

최근 주문량이 급증하면서 기존 엑셀/메모장 기반 관리 방식에 다음과 같은 문제가 발생했다.

- 주문 처리 여부를 확인하기 어려움
- 공정 완료 시점을 예측할 수 없음
- 재고가 충분한데도 불필요한 생산이 진행됨

### 1.2 목적

체계적인 시료 주문 및 생산 흐름 관리를 위한 **콘솔 기반 반도체 시료 생산주문관리 시스템**을 개발한다.

## 2. 목표

| 목표 | 설명 |
|---|---|
| 주문 추적 | 주문 접수부터 출고까지 전체 상태를 실시간으로 파악 |
| 재고 관리 | 시료별 재고 현황과 주문 대비 재고 상태를 한눈에 확인 |
| 생산 자동화 | 재고 부족 시 생산 라인에 자동 등록 및 FIFO 스케줄링 처리 |
| 데이터 영속성 | 애플리케이션 재실행 후에도 데이터 유지 |

## 3. 사용자 및 역할

| 역할 | 설명 | 주요 행동 |
|---|---|---|
| 고객 | 시료 요청자 | 필요한 시료를 이메일로 요청 |
| 주문 담당자 | 주문서 관리 | 요청에 맞게 주문서 작성 및 접수 |
| 생산 담당자 | 시료 생산·승인 | 개발 시료 등록, 주문 수신 후 승인 또는 거절 |

> 본 시스템에서는 주문 담당자와 생산 담당자가 동일한 콘솔에서 작업한다고 가정한다.

---

## 4. 주문 상태 흐름

```
RESERVED
  ├─ 거절 → REJECTED                          (모니터링 제외)
  └─ 승인
       ├─ 재고 충분 → CONFIRMED → RELEASED
       └─ 재고 부족 → PRODUCING → CONFIRMED → RELEASED
```

| 상태 | 의미 |
|---|---|
| RESERVED | 주문 접수 |
| REJECTED | 주문 거절 |
| PRODUCING | 주문 승인 완료 + 재고 부족으로 생산 중 |
| CONFIRMED | 주문 승인 완료 + 출고 대기 중 |
| RELEASED | 출고 완료 |

## 5. 기능 요구사항

### 5.1 메인 메뉴

- [ ] 시스템 현재 시각 표시
- [ ] 시스템 현황 요약 표시
  - 등록 시료 수, 총 재고 수량
  - 전체 주문 수, 생산라인 대기 수
- [ ] 메뉴 선택 화면 제공
  - [1] 시료 관리
  - [2] 시료 주문
  - [3] 주문 승인/거절
  - [4] 모니터링
  - [5] 생산라인 조회
  - [6] 출고 처리
  - [0] 종료

### 5.2 시료 관리

- [ ] **시료 등록**
  - 입력: 시료 ID, 이름, 평균 생산시간(min/ea), 수율(0~1), 초기 재고
  - 중복 시료 ID 등록 방지
- [ ] **시료 목록 조회**
  - 등록된 모든 시료 표시
  - 시료 ID, 이름, 평균 생산시간, 수율, 현재 재고 수량 포함
- [ ] **시료 검색**
  - 이름 키워드로 검색 (부분 일치)

### 5.3 시료 주문

- [ ] 입력: 시료 ID, 고객명, 주문 수량
- [ ] 존재하지 않는 시료 ID 입력 시 오류 안내
- [ ] 입력 내용 확인 후 [Y] 예약 접수 / [N] 취소
- [ ] 접수 완료 시 주문번호 발급 (형식: `ORD-YYYYMMDD-NNNN`)
- [ ] 접수된 주문 상태: RESERVED

### 5.4 주문 승인/거절

- [ ] RESERVED 상태 주문 목록 표시
- [ ] 주문 번호 선택 후 승인 또는 거절 처리
- [ ] **승인 처리**
  - 재고 확인
  - 재고 충분(재고 ≥ 주문 수량) → 즉시 CONFIRMED, 재고 차감
  - 재고 부족(재고 < 주문 수량) → 생산 라인 자동 등록, 상태 PRODUCING
- [ ] **거절 처리**
  - 즉시 REJECTED 상태로 전환

### 5.5 모니터링

- [ ] **주문량 확인**
  - 상태별 주문 수 표시: RESERVED / CONFIRMED / PRODUCING / RELEASED
  - REJECTED 제외
- [ ] **재고량 확인**
  - 시료별 현재 재고 수량 표시
  - 재고 상태 표기
    - **여유**: 주문 대비 재고 충분
    - **부족**: 주문 대비 재고 수량 부족
    - **고갈**: 재고 수량 0

### 5.6 생산 라인

- [ ] **생산량 계산**
  - 실 생산량: `ceil(부족분 / (수율 × 0.9))`
  - 총 생산 시간: `평균 생산시간 × 실 생산량`
- [ ] **스케줄링**: FIFO (선입선출)
- [ ] **생산 현황 표시**
  - 현재 생산 중인 주문 정보 (주문번호, 시료명, 주문량, 부족분, 실생산량, 예상 완료 시각)
- [ ] **대기 주문 목록 표시**
  - 생산 큐의 대기 주문 목록 (순서, 주문번호, 시료명, 주문량, 부족분, 실생산량, 예상 완료 시각)
- [ ] **생산 완료 처리**
  - 생산 완료 시 재고 증가, 주문 상태 PRODUCING → CONFIRMED

### 5.7 출고 처리

- [ ] CONFIRMED 상태 주문 목록 표시
- [ ] 주문 번호 선택 후 출고 실행
- [ ] 출고 완료 시 주문 상태 CONFIRMED → RELEASED

## 6. 비기능 요구사항

| 항목 | 요구사항 |

| 데이터 영속성 | SQLite DB에 저장하여 재실행 후에도 데이터 유지 |

---

## 7. 제약 조건

- 시스템에 등록된 시료만 주문 가능
- 생산 라인은 단일 라인 (하나씩 순차 처리)
- REJECTED 주문은 모니터링 및 통계에서 제외
- 콘솔(CLI) 기반으로만 동작

## 8. 데이터 모델

### Sample (시료)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| sample_id | TEXT (PK) | 시료 고유 ID (예: S-001) |
| name | TEXT | 시료 이름 |
| avg_production_time | REAL | 평균 생산시간 (min/ea) |
| yield_rate | REAL | 수율 (0.0 ~ 1.0) |
| stock | INTEGER | 현재 재고 수량 |

### Order (주문)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| order_id | TEXT (PK) | 주문번호 (예: ORD-20260612-0001) |
| sample_id | TEXT (FK) | 시료 ID |
| customer_name | TEXT | 고객명 |
| quantity | INTEGER | 주문 수량 |
| status | TEXT | 주문 상태 |
| created_at | TEXT | 주문 생성일시 (ISO 8601) |

### ProductionQueue (생산 큐)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| queue_id | INTEGER (PK) | 큐 순번 (AUTO INCREMENT) |
| order_id | TEXT (FK) | 주문번호 |
| actual_production_qty | INTEGER | 실 생산량 |
| total_production_time | REAL | 총 생산 시간 (min) |
| enqueued_at | TEXT | 큐 등록 일시 |
